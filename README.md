# My projects

Hi! My name is not Einar Hjortdal. I am an exercise physiologist and developer.

## The building blocks

- [firebird](https://github.com/einar-hjortdal/firebird): Firebird >5 compatible client library
- [redict](https://github.com/einar-hjortdal/redict): Redict client library (Redis <=7.2.4 compatible)
- [sessions](https://github.com/einar-hjortdal/sessions): framework-agnostic session management
- [blobly](https://github.com/einar-hjortdal/blobly): central BLOB server as a simple alternative to cloud solutions
- [lexical_uuid](https://github.com/einar-hjortdal/lexical_uuid): sortable UUID-compatible ids predating UUIDv7
- [dotenv](https://github.com/einar-hjortdal/dotenv): minimal implementation of [bkeepers/dotenv](https://github.com/bkeepers/dotenv) in V
- [slugify](https://github.com/einar-hjortdal/slugify): create human-friendly url segments
